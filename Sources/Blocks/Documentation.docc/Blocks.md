# ``Blocks``

🧱 Some dependency-free building blocks for my Swift adventures.

## Overview

- <doc:Transport> A set of tools and techniques to write simple and low-footprint networking code, that makes  composition and tests easy to write.
- **API Management**. Some helpers to deal with common pitfalls of the native
  support of JSON API via Swift's `Codable`.
- **Web tooling**. Create JSON Feeds, sitemaps.
- <doc:MarkdownFrontMatter> Write YAML front matter for Markdown files.
- **Data Management**. Convert data to hexadecimal or base 64 at ease.
- <doc:FilenamesAndSlugs> Make a filename or a URL slug from a title.
- **iCalendar Objects**. Create ical documents.
- <doc:StyledText> Compose colored and formatted text for command-line interfaces.
- <doc:InteractiveShell> Run external commands with full terminal access.
- <doc:ReadingALine> Read a line that the user can edit with the arrow keys.
- <doc:RunningProcesses> Run executables without a shell and capture stdout
  and stderr separately.
- <doc:WatchPairing> Find out whether an Apple Watch is paired with the iPhone.
- <doc:ImageCompression> Compress images to a target size, with presets for the network condition.
